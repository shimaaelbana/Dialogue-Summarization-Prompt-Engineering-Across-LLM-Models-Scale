# Dialogue Summarization: Prompt Engineering Across Model Scale

Zero-shot, one-shot, and few-shot prompting for dialogue summarization on the
[DialogSum](https://huggingface.co/datasets/knkarthick/dialogsum) dataset,
comparing **FLAN-T5-base (250M)** and **FLAN-T5-large (780M)**, evaluated with
ROUGE-1 / ROUGE-2 / ROUGE-L against human reference summaries.

## Motivation

In-context learning (zero/one/few-shot prompting) is often presented as a
uniform effect, but how much it helps typically depends on model scale. This
project quantifies that: does moving from one-shot to few-shot prompting
help a 250M-parameter model as much as it helps a 780M-parameter model, and
is the ROUGE gain worth the extra prompt length?

## Method

- **Dataset:** DialogSum test split, 500 multi-turn dialogues with human
  reference summaries.
- **Models:** `google/flan-t5-base`, `google/flan-t5-large` (Hugging Face
  `transformers`).
- **Prompting:** zero-shot / one-shot / few-shot (3 exemplars), built with
  the FLAN-T5 `Dialogue: ... What was going on?` template.
- **Evaluation:** ROUGE-1/2/L F-measure (`rouge-score`), averaged over a
  held-out set of test indices disjoint from the exemplar dialogues.

## Repository structure

```
src/
  data.py        # DialogSum loading
  prompting.py   # zero/one/few-shot prompt construction
  generate.py    # model loading + generation
  evaluate.py    # ROUGE scoring
  pipeline.py    # orchestrates the model x shot-config comparison
kaggle/
  dialogue_summarization_prompting.ipynb   # self-contained Kaggle notebook
results/
  results.csv    # generated by the pipeline
requirements.txt
```

## Running it

**Locally / any environment with a GPU or CPU:**

```bash
pip install -r requirements.txt
python -c "
from src.pipeline import run_experiment
df = run_experiment(
    model_names=['google/flan-t5-base', 'google/flan-t5-large'],
    test_indices=[200, 250, 300, 350, 400],
)
df.to_csv('results/results.csv', index=False)
print(df)
"
```

**On Kaggle:** open `kaggle/dialogue_summarization_prompting.ipynb` as a new
Kaggle notebook (Internet must be enabled under Notebook Settings), run all
cells. It clones this repo and reuses the same `src/` code, so results are
directly reproducible from the numbers reported above.
