# Dialogue Summarization: Prompt Engineering Across Model Scale

Zero-shot, one-shot, and few-shot prompting for dialogue summarization on the
[DialogSum](https://huggingface.co/datasets/knkarthick/dialogsum) dataset,
comparing **FLAN-T5-base (250M)** and **FLAN-T5-large (780M)**, evaluated with
ROUGE-1 / ROUGE-2 / ROUGE-L against human reference summaries.

## Motivation

In-context learning (zero/one/few-shot prompting) is often presented as a
uniform effect, but how much it helps typically depends on model scale. This
project quantifies that: does moving from one-shot to few-shot prompting
help a 250M-parameter model as much as it helps a 780M-parameter model, and
is the ROUGE gain worth the extra prompt length?

## Method

- **Dataset:** DialogSum test split, 500 multi-turn dialogues with human
  reference summaries.
- **Models:** `google/flan-t5-base`, `google/flan-t5-large` (Hugging Face
  `transformers`).
- **Prompting:** zero-shot / one-shot / few-shot (3 exemplars), built with
  the FLAN-T5 `Dialogue: ... What was going on?` template.
- **Evaluation:** ROUGE-1/2/L F-measure (`rouge-score`), averaged over a
  held-out set of test indices disjoint from the exemplar dialogues.

## Results

Evaluated on 5 held-out DialogSum test dialogues (indices disjoint from the
3 few-shot exemplars), FLAN-T5-base and FLAN-T5-large, greedy decoding:

| Model            | Shot config | ROUGE-1 | ROUGE-2 | ROUGE-L |
|------------------|-------------|---------|---------|---------|
| flan-t5-base     | zero-shot   | 0.300   | 0.078   | 0.239   |
| flan-t5-base     | one-shot    | 0.302   | 0.079   | 0.241   |
| flan-t5-base     | few-shot    | 0.295   | 0.083   | 0.248   |
| flan-t5-large    | zero-shot   | 0.316   | 0.100   | 0.243   |
| flan-t5-large    | one-shot    | 0.320   | 0.117   | 0.243   |
| flan-t5-large    | few-shot    | 0.329   | 0.126   | 0.254   |

### Findings

- **Few-shot prompting helps the larger model more.** Going from zero-shot to
  few-shot, flan-t5-large gains +0.013 ROUGE-1 and +0.026 ROUGE-2, while
  flan-t5-base is roughly flat on ROUGE-1 (-0.005) with a smaller ROUGE-2
  gain (+0.005). This matches the general expectation that in-context
  learning benefits scale with model capacity — the smaller model doesn't
  extract much extra signal from the additional exemplars.
- **ROUGE-L improves for both models** with more exemplars (base: 0.239 →
  0.248; large: 0.243 → 0.254), suggesting exemplars mainly help the models
  produce summaries with better sentence-level structure, more than they
  change word-level content overlap (ROUGE-1/2).
- **One-shot is a weak middle ground** — it barely moves the needle over
  zero-shot for either model. The real effect only shows up at 3 exemplars.

### Debugging note: silent context truncation

The first run of this experiment showed few-shot performing *worse* than
zero-shot (ROUGE-L 0.13 vs 0.23 for flan-t5-base), with generations
completely unrelated to the input dialogue. Root cause: the tokenizer call
in `src/generate.py` used `truncation=True` with no explicit `max_length`,
and Hugging Face tokenizers truncate from the **right** by default. Since
few-shot prompts are built as `[exemplar 1][exemplar 2][exemplar 3][target
dialogue]`, any prompt that exceeded the tokenizer's default length limit
silently dropped the target dialogue itself — the model was summarizing
truncated exemplar text instead. Fixed by setting `tokenizer.truncation_side
= "left"` and an explicit `max_length=1024`, so truncation (if any) removes
the earliest exemplar rather than the dialogue being summarized.

## Repository structure

```
src/
  data.py        # DialogSum loading
  prompting.py   # zero/one/few-shot prompt construction
  generate.py    # model loading + generation
  evaluate.py    # ROUGE scoring
  pipeline.py    # orchestrates the model x shot-config comparison
kaggle/
  dialogue_summarization_prompting.ipynb   # self-contained Kaggle notebook
results/
  results.csv    # generated by the pipeline
requirements.txt
```

## Running it

**Locally / any environment with a GPU or CPU:**

```bash
pip install -r requirements.txt
python -c "
from src.pipeline import run_experiment
df = run_experiment(
    model_names=['google/flan-t5-base', 'google/flan-t5-large'],
    test_indices=[200, 250, 300, 350, 400],
)
df.to_csv('results/results.csv', index=False)
print(df)
"
```

**On Kaggle:** open `kaggle/dialogue_summarization_prompting.ipynb` as a new
Kaggle notebook (Internet must be enabled under Notebook Settings), run all
cells. It clones this repo and reuses the same `src/` code, so results are
directly reproducible from the numbers reported above.
